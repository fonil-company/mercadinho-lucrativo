# Gôndola Magnética — LP Mercado/Supermercado

Landing page de vendas do produto "+50 Layouts de Gôndolas Magnéticas", nicho mercado/supermercado. Gerada inicialmente no Lovable a partir do prompt em `docs/prompt-original-lovable.md` e adaptada manualmente a partir daqui — esta pasta é a matriz de onde as próximas variações (Farmácia, Material de Construção etc.) serão modeladas.

## Stack

- TanStack Start (React 19 + SSR) + Vite + Tailwind CSS 4 + shadcn/radix

## Scripts

- `bun run dev` — ambiente local
- `bun run build` — build de produção
- `bun run preview` — pré-visualizar o build
